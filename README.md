## About Me

I'm a **BS Artificial Intelligence student (2024–2028)** at Shifa Tameer-e-Millat University, focused on turning machine-learning concepts into practical software.

My current focus is **applied AI**, especially retrieval-augmented generation, LLM integration, semantic retrieval, and AI agents.

I'm currently developing two larger AI projects:

* **TradeReady AI** — an AI system focused on trade-compliance workflows, document processing, retrieval, evidence, and evaluation.
* **JARVIS-X** — an intelligent desktop-automation agent exploring planning, execution, verification, recovery, memory, and permission-controlled actions.

I also have a foundation in **classical machine learning** including classification, regression, clustering, feature engineering, and model evaluation using Scikit-learn.

I'm actively interested in **AI/ML internships, Python development, applied AI, RAG/LLM applications, and AI agent projects**.
